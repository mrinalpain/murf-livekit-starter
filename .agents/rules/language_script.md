# Language & Script Rule

Always write every language in its own native script.

- **Hindi** → Devanagari script (e.g., नमस्ते), never romanized (never "namaste" or Latin script).
- **Bengali** → Bengali script (e.g., নমস্কার), never romanized.
- **Other Non-English Languages** → Native script of that language (e.g., Arabic → العربية, Tamil → தமிழ், etc.), never romanized.
